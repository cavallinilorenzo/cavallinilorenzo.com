# Fully static site

Every page is prerendered at build time and the site runs no server-side code: no route handlers, server actions, ISR, proxy/middleware, or host-only services. `next build` runs with `output: 'export'` and writes plain files to `out/`, which Cloudflare Workers static assets serves on `cavallinilorenzo.com` (`wrangler.jsonc`); we moved off Vercel Hobby, whose non-commercial terms the Freelance page arguably breached. A feature that needs a server is rejected or done in the browser. `redirects()` in `next.config.ts` is dropped under `output: 'export'`, so redirects live in `public/_redirects` and are covered by `e2e/redirects.spec.ts`, which runs against `wrangler dev`.
